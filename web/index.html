💡 Hướng dẫn nạp lịch vào các thiết bị

  • 1
    Google Calendar (Lịch Google): Truy cập calendar.google.com → Bấm biểu tượng ⚙️ Cài đặt → Chọn Import & Export → Chọn file .ics vừa tải về và bấm nạp.
  • 2
    Apple Calendar (Lịch trên iPhone / Macbook): Trên máy tính Mac: Mở ứng dụng Lịch → Chọn File → Chọn Import... và chọn file .ics. Trên iPhone: Gửi file .ics này qua Zalo/Email cho chính mình và bấm trực tiếp vào tệp tin → chọn Thêm tất cả sự kiện.
  • 3
    Microsoft Outlook: Chọn File → Chọn Open & Export → Chọn Import/Export → Chọn nạp file iCalendar (.ics) để đồng bộ!
